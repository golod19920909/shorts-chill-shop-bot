## 5. AliExpress Affiliate API

Официальная документация AliExpress/TOP подтверждает:
- `aliexpress.affiliate.category.get` существует как Affiliate API для получения списка категорий. Ответ содержит `categories.category[]`: `category_id`, `category_name`, `parent_category_id`, `total_result_count`. Документация помечает метод как не требующий авторизации.
- `aliexpress.affiliate.product.query` принимает необязательный параметр `category_ids` — список ID через запятую. Ответ содержит `first_level_category_id/name` и `second_level_category_id/name`.

Ограничения текущего кода:
- `services/marketplaces/aliexpress_client.py` объявляет `METHOD_CATEGORY_GET` (1 упоминание), но отдельный вызов/нормализатор ответа category.get не реализован.
- В provider `services/marketplaces/aliexpress.py` вызов category.get не обнаружен (0 упоминаний метода).
- Параметр `category_ids` не подключён к текущему поисковому пути product.query.
- Нормализатор использует названия first/second level category для `category_path`, но не сохраняет ID для таксономического сопоставления.
- В этом окружении нет доступа к локальному `.env`; live-ответ category.get не получен.

Официальные источники:
- [AliExpress Affiliate category.get](https://developer.alibaba.com/docs/api.htm?apiId=45801)
- [AliExpress Affiliate product.query](https://jaq-doc.alibaba.com/docs/api.htm?apiId=45803)

**Вывод:** спецификация API предоставляет нужные методы. Следующий шаг — отдельная безопасная live-проверка category.get с локальными credentials пользователя и сохранение ответа без секретов. Не записывать ID в конфигурацию до проверки соответствия.

## 7. Ограничения доказательств и следующие шаги

- Raw search не доказывает достаточный ассортимент после строгой проверки идентичности.
